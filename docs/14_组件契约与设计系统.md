# 14 · 组件契约与设计系统

| 项目 | 内容 |
| --- | --- |
| 归属 | Atomlet 小原子 |
| 版本 | v1.0，与 `13_UI交互与视觉规范.md` 配套使用 |

## 2 基础组件清单

`props` 按 `名:类型=默认值` 书写，未标默认即为必填；所有组件都继承 `className`，不再重复列出。

关于 shadcn/ui：本项目不执行 `shadcn init`（省掉 Radix 依赖安装与初始化约 20 分钟），但组件 API 全部按 shadcn 命名，后续可一对一平替：Button→`Button`、Input→`Input`、Textarea→`Textarea`、Select→`Select`、Checkbox→`Checkbox`、Modal→`Dialog`、Tabs→`Tabs`、Toast→`Sonner`、Tooltip→`Tooltip`；Table、Pagination、Badge、Skeleton、EmptyState、Stepper 在 shadcn 中无对应物，需自研。

| 组件 | 用途 | 实现载体 | 复杂度 | 工时 | 级别 |
| --- | --- | --- | --- | --- | --- |
| Button | 所有动作触发 | 自研（Tailwind 变体） | 低 | 12 | P0 |
| Input | 单行文本 / 数字 / 日期 | 自研 | 低 | 12 | P0 |
| Select | 枚举单选 | 自研（基于原生 + 浮层） | 中 | 10 | P0 |
| Textarea | 多行文本 | 自研（复用 Input 外壳） | 低 | 4 | P0 |
| Checkbox | 布尔与多选 | 自研 | 低 | 6 | P0 |
| Table | 数据列表主体 | 自研 | 高 | 26 | P0 |
| Pagination | 列表翻页 | 自研 | 低 | 8 | P0 |
| Tabs | 页面组 / 双栏切换 | 自研 | 低 | 8 | P0 |
| Modal | 确认与表单弹层 | 自研（含焦点陷阱） | 中 | 14 | P0 |
| Toast | 结果反馈 | 自研（aria-live） | 低 | 8 | P0 |
| Badge | 状态与计数 | 自研 | 低 | 4 | P0 |
| Skeleton | 加载占位 | 自研 | 低 | 4 | P0 |
| EmptyState | 空态 | 自研 | 低 | 8 | P0 |
| Stepper | 三阶段进度 | 自研 | 中 | 14 | P0 |
| Tooltip | 口径说明 | 自研（CSS hover + focus） | 低 | 8 | P1 |

| 组件 | props | 状态要点 | 无障碍要点 |
| --- | --- | --- | --- |
| Button | `variant:'primary'\|'secondary'\|'ghost'\|'danger'=primary`、`size:'sm'\|'md'\|'lg'=md`、`loading:bool=false`、`disabled:bool=false`、`fullWidth:bool=false`、`icon?:LucideIcon` | loading 时宽度锁死，文案换成进行时 | 原生 `button`；loading 加 `aria-busy`；纯图标必须有 `aria-label` |
| Input | `value:string`、`onChange`、`type:'text'\|'number'\|'date'\|'file'=text`、`invalid:bool=false`、`hint?:string`、`error?:string` | invalid 时描边 danger + 下方文案 | `label for` 必填；`aria-invalid` + `aria-describedby` 指向错误 |
| Select | `options:{value,label}[]`、`value:string`、`onChange`、`placeholder?:string`、`searchable:bool=false`、`invalid:bool=false` | 打开时浮层 `shadow-2`，选中项打勾 | `role="listbox"`，方向键 + Enter + Esc |
| Textarea | `rows:number=4`、`value`、`onChange`、`maxLength?:number`、`invalid:bool=false` | 右下角字数 `12/200`（仅设了 maxLength） | 同上，`<textarea>` 原生语义 |
| Checkbox | `checked:bool`、`onChange`、`indeterminate:bool=false`、`label?:string` | indeterminate 用于表头全选 | 用 `input type=checkbox`，label 可点 |
| Table | `columns:Column[]`、`rows:T[]`、`rowKey:string`、`sortable:bool=false`、`onSort?`、`emptyText:string`、`dense:bool=false` | 排序三态 asc/desc/none；空态保留表头 | `th scope="col"`、`aria-sort`、容器 `role="region"` + `tabIndex=0` |
| Pagination | `page:number`、`pageSize:number=20`、`total:number`、`onChange` | 只有 1 页时不渲染 | `nav` + `aria-label="分页"`，当前页 `aria-current` |
| Tabs | `items:{key,label,count?}[]`、`value:string`、`onChange` | 下划线 2px primary，切换无位移 | `role="tablist"`，左右键切换 |
| Modal | `open:bool`、`onClose`、`title:string`、`size:'sm'\|'md'=md`、`footer?:ReactNode`、`closeOnEsc:bool=true` | 遮罩 40% N8；无入场动画，只有 120ms 透明度 | 焦点陷阱、`aria-modal`、关闭回触发元素 |
| Toast | `toast({title,description?,variant:'success'\|'error'\|'info'=info,duration?=3000,action?})` | 右下堆叠，最多 3 条 | `aria-live="polite"`，错误用 assertive |
| Badge | `variant:'neutral'\|'success'\|'warning'\|'danger'\|'info'=neutral`、`size:'sm'\|'md'=sm` | 只用语义 4 色 + 中性 | 颜色必须配文字，不单独表意 |
| Skeleton | `lines:number=3`、`variant:'text'\|'block'=text` | 高度等于最终内容高度 | `aria-hidden`，容器加 `aria-busy` |
| EmptyState | `title:string`、`description?:string`、`action?:{label,onClick}`、`icon?:LucideIcon` | 居中，上下留白 48px | 标题用 `h3`，动作是真按钮 |
| Stepper | `steps:{key,label,status:'pending'\|'running'\|'done'\|'failed'}[]`、`current:number`、`onStepClick?` | 只有 done 可点，hover 显示「回看」 | `ol` + `aria-current="step"`，状态用文字播报 |
| Tooltip | `content:string`、`side:'top'\|'bottom'=top`、`delay:number=200` | 只做 hover + focus，不做 click | focus 也能触发，`aria-describedby` |

## 3 runtime 页面组件契约

生成出来的应用由 6 种组件拼装，全部受 AppSpec 驱动，不允许自由布局。

### 3.1 form

字段类型 → 控件映射（唯一映射，不做智能猜测）。

| AppSpec `field.type` | 控件 | 附加规则 |
| --- | --- | --- |
| `text` | Input text | ≤ 200 字，单行，最大宽 100% |
| `longtext` | Textarea rows=4 | ≤ 2000 字，超过 200 字显示计数 |
| `number` | Input number | 右对齐等宽，受 `min` / `max` 约束 |
| `date` | Input date | 存 `YYYY-MM-DD`；展示时同年省略年份 |
| `enum` | Select | 选项 = `field.enum`；≤ 5 项时退化为单选组 |
| `bool` | Checkbox | 标签在控件右侧，初始值取 `field.default` |
| `url` | Input text（`inputMode=url`） | 只接受 http/https，提交前本地校验 |
| `ref` | Select searchable | 选项来自 `ref.entity` 的 `displayField`，最多取 50 条 |
| `user` | 只读文本（取 session） | 不渲染输入框，客户端不可编辑 |

- 校验展示：标签后 `*`（danger，与文字间距 4px）；错误在字段下方 4px、14px danger、单条不堆叠。
- 校验时机：onBlur 与 submit；提交失败滚动到第一个错误并聚焦。
- 提交反馈：按钮进 loading（文案「提交中…」）；成功后表单重置但保留上一个枚举值；失败保留全部输入。

### 3.2 table

| 项 | 契约 |
| --- | --- |
| 列定义 | `columns:[{field,label}]`，不给宽度，按内容自适应；数字列自动右对齐 |
| 排序 | `defaultSort:{field,dir}` 初始化；点列头单列切换 asc → desc → 取消 |
| 筛选 | `filters:[{field,op}]`，op ∈ `eq/neq/contains/gt/gte/lt/lte`；枚举渲染多选，其余渲染输入框 |
| 格式 | number 右对齐等宽；date 用 `MM-DD HH:mm`；enum 走 Badge 语义色 |
| 行操作 | `rowAction:"detail"` 点击行进详情；删除为独立按钮 + Modal 二次确认 |
| 空态 | 无数据：「还没有数据，去表单填一条或分享链接让别人填」；筛选无结果：「没有符合条件的记录 · 清空筛选」 |
| 分页 | 按 `pageSize`（默认 20）分页，总数 ≤ pageSize 时不渲染分页 |

### 3.3 detail

- 字段按 `fields` 数组顺序渲染；超过 8 个字段时拆成「基本信息 / 其他」两组，组标题 14/20/600，组间距 24px。
- 两列栅格（≥md），<md 降为单列；标签在上、值在下，标签 12px N6。
- 长文本 > 120 字折叠 3 行 +「展开」，展开后不自动折回。
- 空值统一渲染 `—`（N5），不渲染空白格。
- 顶部动作固定为「编辑」（secondary）+「返回列表」（ghost）。

### 3.4 stats

| 项 | 契约 |
| --- | --- |
| 指标卡 | `cards:[{label,fn,field?,unit?,filter?}]`，fn ∈ `count` / `sum` / `avg`；unit 直接拼在数值后 |
| 数值排版 | 24/32/600；同一行所有数值卡等宽、等高 |
| 口径提示 | 卡片标题右侧 Tooltip 图标，文案固定「统计全部 23 条记录，包含未完成的」 |
| 点击行为 | 点卡片跳到该卡片 `filter` 生效后的列表（无 filter 则跳全量列表） |
| 无数据 | 显示 `0`，不显示 `—` 也不要空卡 |

### 3.5 board

- 分组维度来自 `groupBy`，必须是本 entity 的 enum 字段；只有 1 个维度，多于 1 个在生成阶段就拒绝。
- 卡片标题取 `titleField`，卡身按 `cardFields` 列 3 行，超出截断。
- 卡片底部动作走 `updateAction`，拖拽换列 = 改 `groupBy` 外的状态字段（P1 才做拖拽）。
- 空列渲染「暂无」占位，不隐藏列（隐藏会让看板形变）。
- P1：拖拽改分组；降级形态为列头下拉切换 `groupBy`。

### 3.6 chart

| 数据形态 | 图型 | 说明 |
| --- | --- | --- |
| 枚举维度 + 数值，类别 ≤ 6 | 横向柱状 | 默认首选，标签好读 |
| 枚举维度 + 数值，类别 > 6 | 纵向柱状 + Top 6 | 其余归入「其他」 |
| 连续时间 ≥ 7 个点 | 折线 | 只连数据点，点上不标数值 |
| 连续时间 < 7 个点 | 柱状 | 点太少折线会误导趋势 |
| 占比且类别 ≤ 4 | 环形 | 中心显示总量 |
| 占比且类别 > 4 | 禁止饼图，改横向柱 | 超过 4 片的饼图不可读 |

颜色序列上限 6 个，按序取：`#4F46E5`、`#0D9488`、`#D97706`、`#E11D48`、`#7C3AED`、`#0891B2`；第 7 类起统一用 `#94A3B8` 并归为「其他」。图表不给入场动画，只保留 hover tooltip。`chartType` 只接受 `bar` / `line` / `donut` 三值，上表是 Builder 选型规则，也是渲染器遇到越界值时的兜底依据。

## 5 应用主题系统

生成的应用只允许通过 AppSpec 的 4 个字段换皮，不允许改布局、不允许自定义 CSS。字段口径与 `07 文档` / `08 文档` 的 `apps` 表 CHECK 约束保持一致。

| AppSpec 字段 | 作用 | 取值集合 | 默认 |
| --- | --- | --- | --- |
| `app.name` | 顶栏、分享页标题、填报页页脚 | 字符串，≤ 20 字（超出截断并加省略号） | 由需求推断，兜底「新应用」 |
| `app.description` | 工作台卡片与填报页顶部的一句话 | 字符串，≤ 40 字 | 空 |
| `app.icon` | 侧栏与卡片图标 | lucide 白名单：`clipboard-check` / `wrench` / `ticket` / `users` / `box` / `calendar` / `chart-line` / `file-text` | `atom` |
| `app.theme` | 主题色，只替换 primary 三值 | `neutral`（#4F46E5）/ `warm`（#B45309）/ `cool`（#0D9488） | `neutral` |

约束：`theme` 只覆盖 `primary`、`primary-hover`、`primary-soft` 三个 token，语义色与中性 9 阶不随主题变化；图标只从 lucide-react 已安装集合映射，不新增依赖；换主题不改变任何尺寸与间距。

## 6 视觉验收清单（15 条，逐条肉眼可判）

| # | 验收项 | 判定 |
| --- | --- | --- |
| 1 | 按钮文案不换行，不出现两行高的按钮 | 截图看按钮高度是否与 token 一致 |
| 2 | 同一屏内实心 primary 按钮 ≤ 1 个 | 数一数 |
| 3 | 正文与背景对比度 ≥ 4.5:1 | 取色器抽 3 处 |
| 4 | 空列表一定有「表头 + 一句解释 + 一个动作」 | 手动删光数据看 |
| 5 | 加载中不产生布局跳动 | 慢网刷新，观察内容是否位移 |
