# 13 · UI 交互与视觉规范

| 项目 | 内容 |
| --- | --- |
| 产品 / 版本 | Atomlet 小原子 · 规范 v1.0（对应 AppSpec v1） |
| 画布基准 | 桌面 1440×900；最小 375×667 |
| 技术前提 | Next.js 14 App Router + Tailwind CSS 3.4；无拖拽布局；无暗色模式；不用动画库（仅 CSS transition / keyframes） |
| 配套文档 | `14_组件契约与设计系统.md`（token、组件 props、工时） |
| 界面预算 | P0 实现 180 分钟；超出项在 14 文档标 P1 并给降级形态 |

## 1 设计原则

| # | 原则 | 判断标准 | 落地手段 |
| --- | --- | --- | --- |
| D1 | 生成过程必须可见 | 从点「开始生成」到应用出现，任意时刻都有元素在变，用户不用猜「卡了没」 | 步骤条 / 流式 token / 骨架屏，至少一者在动 |
| D2 | 一眼看出这是真系统 | 预览区至少有一个可点的表格行和一个能提交的表单，整屏没有「截图感」 | 预览渲染真实组件，示例数据随生成一起写入 |
| D3 | 每屏只有一个主动作 | 同一屏内实心 primary 按钮 ≤ 1 个，出现两个即判缺陷 | 主按钮固定在页头右侧或内容区右下 |
| D4 | 生成物可审阅、可回滚 | 每次修改都能看到「改了哪几项」和「回到上一版」 | 差异摘要 + 版本号 +1 + 版本历史页 |

## 5 关键交互流程

### 5.1 上传表格 → 出应用

| # | 触发 | 界面反馈 | 异常与兜底 |
| --- | --- | --- | --- |
| 1 | 拖入文件 | 上传卡边框变主色 2px 虚线 + 「松手即可上传」 | 扩展名不符：边框 danger +「只支持 .xlsx 和 .csv」，不读文件 |
| 2 | 松手 | 卡片 loading：3 行 Skeleton + 「正在读表头和前 20 行」 | 超 5MB：「文件 8.3 MB，超过 5 MB 上限」，先校验再上传 |
| 3 | 解析成功 | 跳 S2，摘要「23 行 × 8 列 · 8 个字段」 | 解析失败：留原页，展开错误卡（6.5 模板 1） |
| 4 | 点开始生成 → 生成中 | 按钮立即 loading 并跳 S3，首帧即完整骨架；步骤条分段推进，每页写完淡入替换，结束时浮条「生成完成 · 4 个页面」 | 双击无效：disabled + 请求锁，只发一次；单页失败只标该 Tab，其余继续 |

### 5.2 对话改需求 → 版本 +1

| # | 触发 | 界面反馈 | 异常与兜底 |
| --- | --- | --- | --- |
| 1 | 发送需求 | 输入框清空，插入气泡 +「正在改：位置字段改为下拉」 | 空内容：按钮 disabled，不发请求 |
| 2 | 解析意图 | 差异卡「预计改 2 项：位置 → 下拉；来源 → 设备表」 | 意图不明：「没听懂要改哪一页」+ 3 个候选页面按钮 |
| 3 | 执行修改 | 预览区加 1px 主色描边 +「正在生成 v4」，旧版仍可见 | 失败：恢复 v3，错误卡带「重试」「撤销这次修改」 |
| 4 | 完成 / 回滚 | 提示条「v4 已生效 · 改了 2 项」+「回到 v3」，页头版本号 +1 | 连改两次合并为一次提交，只 +1 版本；回滚只切视图不删 v4 |

### 5.3 分享链接的生成与访问

| # | 触发 | 界面反馈 | 异常与兜底 |
| --- | --- | --- | --- |
| 1 | 点分享 | Modal：只读链接框 +「复制链接」+ 权限单选 | 未落库：先写库再发 token，按钮 loading |
| 2 | 复制成功 | Toast「链接已复制，可以发给同事了」，2 秒消失 | 剪贴板被拒：选中链接文本 +「按 Ctrl+C 复制」 |
| 3 | 外部访问与提交 | 直接渲染表单，无侧栏无登录；提交按钮 loading，成功原地换「已提交 · 可继续填下一条」 | token 失效：整页卡「这个链接已关闭」；校验失败就近显示，不清空已填；主人侧显示「新增 1 条 · 刷新」 |

### 5.4 生成失败与重试

| # | 触发 | 界面反馈 | 异常与兜底 |
| --- | --- | --- | --- |
| 1 | 任一阶段失败 | 该段转 failed，后续段保持 pending；已生成的页面保留可预览 | 错误卡默认展开，不需要二次点击 |
| 2 | 重试 / 跳过 | 从失败段重跑，done 段不回到 pending；跳过则标 skipped 并给「未校验」提示 | 连续失败 2 次出现「换个方式」→ 改用一句话描述 |
| 3 | 刷新页面 | 用 URL 里的 sessionId 恢复进度 | 恢复失败：「这次任务已结束」+「回到工作台」 |

## 6 生成过程的可视化设计（核心体验）

### 6.1 三阶段步骤条

| 阶段 | 角色 | 名称 | 预期耗时 | 用户能看到的产出 |
| --- | --- | --- | --- | --- |
| 1 | Planner | 规划 | 8 秒 | 字段清单 + 页面清单 |
| 2 | Builder | 生成 | 25 秒 | 4 个页面逐个出现 |
| 3 | Critic | 校验 | 7 秒 | 校验报告（通过 / N 处问题） |

| 状态 | 圆点 | 连接线 | 文字色 | 展示内容 | 可点击 |
| --- | --- | --- | --- | --- | --- |
| pending | 16px 空心 1px N4 | 右侧 N3 | N6 | 只有阶段名 | 否 |
| running | 16px 主色实心 + 24px 主色 12% 呼吸圈（1.6s） | 左实右虚 | N8 | 阶段名 + 具体动作 | 否 |
| done | 16px 主色实心 + 10px 白色对勾 | 全实 | N8 | 阶段名 + 一行结果 | 是（回看） |
| failed | 16px danger 实心 + 白色感叹号 | 全实至失败点 | danger | 阶段名 + 一行原因 | 是（展开错误卡） |

### 6.2 每阶段文案（原样抄进代码）

| 阶段 | running | done | failed |
| --- | --- | --- | --- |
| 规划 | 正在读你的表格，拆出要用的字段… | 拆出 8 个字段，规划了 4 个页面 | 没能读懂这张表 |
| 生成 | 正在写第 2/4 个页面：数据列表 | 4 个页面已写好，进入校验 | 生成在第 2 阶段停下了 |
| 校验 | 检查必填、字段类型和页面之间的跳转 | 校验通过，可以预览了 | 生成的表单有 2 个字段对不上 |

### 6.3 流式 token 的呈现

| 项 | 规范 |
| --- | --- |
| 位置 / 尺寸 | 预览区顶部可折叠「生成日志」，展开 120px，最大 280px |
| 字体 / 追加 | `ui-monospace / Menlo`，13px / 20px，色 N7；收到即追加，不做逐字延迟动画 |
| 光标 | 行尾 `▌`，1s 阶跃闪烁（steps(2)），停顿 800ms 后隐藏 |
| 容量 | 保留最近 300 行；完成后折叠为「生成日志 · 4 个页面 / 21 个字段」 |

### 6.4 AppSpec 可展开审阅面板

| 层级 | 内容 | 默认 | 交互 |
| --- | --- | --- | --- |
| L0 摘要卡 | 应用名、页面数、字段数、预计影响 | 展开 | 一行四列，无按钮 |
| L1 页面列表 | 4 个页面条目（类型图标 + 字段数） | 展开 | 点击展开 L2，并切到右侧对应页面 |
| L2 字段表 | 字段名 / 类型 / 必填 / 来源列 | 收起 | 只读表格 |
| L3 原始 JSON | AppSpec 原文 | 收起 | 等宽 12px，只读 +「复制 JSON」 |

### 6.5 失败错误卡片模板

结构固定：标题（18/600）+ 三段（发生了什么 / 为什么 / 怎么办）+ 主次按钮。

- 模板 1 文件解析失败。标题「没能读懂这张表」；发生「第 3 行第 2 列起有合并单元格，后面的字段全错位」；为什么「合并单元格没有唯一列名，没法映射成一个字段」；怎么办「在 Excel 里取消合并后重传，或改用一句话描述」；按钮 `重新上传` / `改用一句话描述`。
- 模板 2 生成超时。标题「生成在第 2 阶段停下了」；发生「写第 3 个页面（统计看板）超过 90 秒没返回」；为什么「这次 4 个页面、21 个字段，超出单次生成预算」；怎么办「点继续生成只补第 3、4 页，或去掉看板只留表单和列表」；按钮 `继续生成` / `减少页面后重来`。
- 模板 3 校验未通过。标题「生成的表单有 2 个字段对不上」；发生「『巡检人』在表单里是文本输入，在列表里是下拉，两处类型不一致」；为什么「原表这一列既有姓名也有工号，推断不稳定」；怎么办「点就地改，把这一列统一成下拉并指定选项来源」；按钮 `就地改` / `先这样预览`。

## 7 交互细节规范表

| # | 场景 | 规范 | 具体取值 / 文案 |
| --- | --- | --- | --- |
| 1 | 首屏加载 | Skeleton 复刻最终布局，不用整页 spinner | 骨架与真实内容同高，不产生跳动 |
| 2 | 按钮加载态 | 宽度不变，左侧 14px 圆环 + 文案换进行时 | 「生成」→「正在生成…」 |
| 3 | 空状态 | 三件套：一句解释 + 一个动作 + 一个图标 | 「还没有数据，去表单填一条或分享链接让别人填」 |
| 4 | 筛选无结果 | 与真空态区分，给清空入口 | 「没有符合条件的记录 · 清空筛选」 |
| 5 | 字段错误 | 就近显示，字段下方 4px，14px danger | 「请填写设备名称」，不弹 Toast |
| 6 | 页面级错误 | 整块错误卡 + 重试，保留顶栏与侧栏 | 不整页白屏 |
| 7 | 按钮禁用条件 | 必填未填 / 请求在途 / 无权限，三选一即禁 | 禁用仍可见，`aria-disabled="true"` |
| 8 | 输入校验时机 | onBlur + submit 校验，不在 onKeyUp 实时报错 | 修改后立即清该字段错误 |
| 9 | 提交成功 | Toast 2 秒，文案 ≤ 8 字 | 「已保存」「已提交」 |
| 10 | Toast 规格 | 右下，宽 ≤ 360px，最多同时 3 条 | 停留 3000ms，错误 5000ms，可手动关 |
| 11 | 防重复提交 | 请求在途锁 + 按钮 disabled，300ms 同参合并 | 双击不会建两条记录 |
| 12 | 长列表 | 默认 20 行/页，总数 > 20 才出分页 | 首列 sticky，横向滚动不带走序号列 |
| 13 | 长文本 | > 2 行截断 +「展开」，展开后不折回 | 详情页 > 120 字折叠 3 行 |
| 14 | 移动端 | < 768px 侧栏变抽屉，双栏改 Tabs | 表格退化为卡片列表 |
| 15 | 焦点管理 | 弹层打开聚焦首个可交互元素，关闭回触发元素 | 提交失败聚焦第一个错误字段 |
| 16 | 复制反馈 | 必须有可见反馈 | 「链接已复制」+ 图标 800ms 内变对勾 |
| 17 | 删除确认 | 删记录、删页面都二次确认 | 「删除后无法恢复，确定删除「设备」页？」 |
| 18 | 数字与时间 | 数字右对齐等宽；时间 <24h 用相对值 | 「12 分钟前」，超过用「05-11 09:00」 |
| 19 | 版本切换 | 切历史版本必须常驻提示条 | 「正在查看 v3（历史版本）· 回到最新」 |
| 20 | 中断与恢复 | 生成中离开页面，回来必须能恢复进度 | 恢复失败给「这次任务已结束」出口 |

## 8 响应式断点

| 断点 | 像素 | 侧栏 | 双栏页（S3/S4） | 表格 |
| --- | --- | --- | --- | --- |
| 默认 | < 640（Tailwind 默认断点，不新增自定义值） | 抽屉 | 对话与预览改 Tabs，默认预览 | 卡片列表，每行 2 个字段 |
| sm | 640–767 | 抽屉 | Tabs，不可并排 | 卡片列表 |
| md | 768–1023 | 56px 图标态 | 双栏 3:7，对话列 ≥ 280px | 真表格 + 横向滚动 |
| lg | 1024–1279 | 200px 展开 | 双栏 4:6 | 真表格，隐藏次要列 |
| xl | ≥ 1280 | 200px | 双栏 4:6，预览区 ≥ 560px | 全部列 |

## 9 无障碍与可用性最低要求

| 项 | 最低要求 | 自检方法 |
| --- | --- | --- |
| 对比度 | 正文 ≥ 4.5:1，≥18px 文字 ≥ 3:1，状态不单靠颜色 | 取色器抽 3 处正文，再转灰度看状态 |
| 焦点可见 | 可交互元素 focus-visible 有 2px 主色描边 + 2px offset | 全程 Tab 走完 S2→S4 |
| 键盘可达 | Tab 顺序合视觉顺序；弹层有焦点陷阱，Esc 可关 | 不用鼠标完成一次生成 |
| 语义与播报 | label 用 for 关联，th 带 scope，标题不跳级；流式日志与 Toast 用 polite，错误用 assertive | 读屏器过一遍 S2，确认不重复播报 |
| 触控目标 | 移动端可点区域 ≥ 44×44px | 375 宽逐一点击 |

## 10 文案规范

### 10.1 按钮动词表

| 场景 | 用这个 | 不要用 |
| --- | --- | --- |
| 首次生成 | 开始生成 | 提交、开始、Go |
| 采纳结果 | 采纳并预览 | 使用、确定 |
| 重跑 | 重新生成 | 重试一次、再来 |
| 保存单页编辑 | 保存修改 | 保存、OK |
| 分享 | 复制链接 | 分享链接、获取链接 |
| 回退 | 恢复此版本 | 回滚、还原 |
| 导出 | 导出 CSV | 导出数据、下载 |
| 上传入口 | 选择文件 | 上传、浏览 |
| 外部提交 | 提交 | 提交表单、发送 |
| 删除 | 删除页面 | 移除、清空 |

### 10.2 微文案语气

- 用「你」，不用「您」「用户」；一条文案只说一件事，不用感叹号，不卖萌（禁止「AI 正在努力思考中…」）；出错时不写「出错了」「操作失败」，必须说清是什么没成。
- 数字与单位之间加空格：`5 MB`、`23 条`、`8 个字段`。

### 10.3 错误提示三段式

结构固定为 **发生了什么 → 为什么 → 怎么办**，每段一句，总长 ≤ 80 字。

- 示例 A：`这份表格读不了。` / 第 3 行有合并单元格，字段对不上。 / 取消合并后重新上传即可。
- 示例 B：`这一条没保存上。` / 网络在提交时断开了。 / 点重试会保留你已经填的内容。
